Calibra needs a local server

Browsers block this app when opened directly from a folder (file://). That is normal — use one of these options:

  1. Easiest: Double-click serve.bat in this folder, then open http://localhost:8080
  2. PowerShell in this folder: 
    .\serve.ps1
  3. Python (if installed): 
    python -m http.server 8080
    Then open http://localhost:8080
  4. GitHub Pages: use the live site if you enabled Pages on the repo

Why? The app uses modern JavaScript modules, which only work over http:// or https:// — not file://.
